## 1. 概述

### 1.1 技术栈

| 项 | 选型 | 说明 |
|---|---|---|
| 前端 | 原生 HTML + CSS + JavaScript | 无框架、无构建、无依赖（ES5 风格，`async/await` 例外） |
| 运行形态 | 安卓 APK（Capacitor WebView）+ 纯网页版 | 同一套 `www/` 资源 |
| 数据存储 | localStorage | 键：`yujian_records_v1`（记录）、`yujian_settings_v1`（设置） |
| 摄像头 | `navigator.mediaDevices.getUserMedia` | 请求 1920×1080，后置摄像头 |
| 图片生成 | Canvas 2D → PNG dataURL | 750px 宽预检单卡片 |
| 分享 | Capacitor Filesystem + Share 插件 | 图片写缓存文件 → 系统分享面板；Web 环境降级 |
| 后端 | 无 | 完全离线，数据不出手机 |

### 1.2 目录结构

```
www/
  index.html       页面结构（表单/记录页/弹窗）
  style.css        样式（移动端优先，大按钮）
  app.js           全部业务逻辑（约 870 行，按区块注释组织）
.github/workflows/
  build-apk.yml    GitHub Actions 云端打包
scripts/
  patch-android.mjs 打包前注入 CAMERA 权限 + 排除 kotlin-stdlib 重复类
```

### 1.3 页面结构

- 两个 Tab 页：**录入**（默认）、**今日记录**
- 弹窗：车牌拍照、预检单预览、设置、删除确认
- 全屏"授权"层：未规划（当前公开分发）

## 3. 数据设计

### 3.1 设置对象 `yujian_settings_v1`

```js
{ stationName: '车辆检测站', inspector: '张三' }
```

### 3.2 记录对象 `yujian_records_v1`（数组）

```js
{
  id: 'r' + 时间戳36进制 + 随机串,   // 唯一
  seq: 1,                            // 当日序号（从 1 递增，按当日条数+1）
  plateNo: '',                       // 已废弃，恒为空串（兼容旧记录）
  gearbox: '手动挡',                  // 变速器
  exhaust: '2',                      // 排气管数量
  mileage: '120000',                 // 行驶公里数
  platePhoto: 'data:image/jpeg;base64,...', // 车牌照片（裁剪后 800px 宽 JPEG 0.8）
  inspector: '张三',
  stationName: '车辆检测站',
  createdAt: ISO 时间串
}
```

### 3.3 存储容量兜底

`saveRecords()` 捕获 `QuotaExceededError`：删除非今日记录重试；仍失败则 alert 提示并仅保留内存数据。照片压缩策略：裁剪 800px + JPEG 0.8（约 20–60KB/张），百台/日仍远低于 5MB 配额。

## 4. 关键流程

### 4.1 车牌拍照（核心交互）

```
点「拍摄车牌照片」
  → openOcrModal：请求摄像头（1920×1080，后置）
  → 视频流显示，叠加取景框（CSS：宽98%、高22%、垂直居中）
  → 点「拍照」：
     captureVideoFrame()      截取当前视频帧（视频源分辨率）
     getGuideRect()           取景框 CSS 坐标 → 视频源像素坐标
     cropPlatePhoto()         按方框裁剪并等比放大到 800px 宽，JPEG 0.8
  → showOcrShot()：写入 currentPlatePhoto → 表单预览显示 → 关闭弹窗（无确认步骤）
```

无法调用摄像头（非 https/被拒）→ `showOcrFallback`：相册选图（`<input type="file">`）→ 整图缩放 1200px → 同样回填。

### 4.2 取景框坐标换算（getGuideRect）

视频容器 `aspect-ratio: 3/4`，视频 `object-fit: cover`（等比填满裁切）：
1. `scale = max(容器宽/视频宽, 容器高/视频高)` → 视频实际显示尺寸 = 视频源尺寸 × scale
2. 水平偏移 `offX = (容器宽 - 视频宽×scale)/2`（水平居中）
3. 取景框 CSS 坐标 → 视频源坐标：`(框坐标 - 视频位置 - offX) / scale`

### 4.3 裁剪放大（cropPlatePhoto）

- 源区域 = 取景框在视频源上的矩形（可越界，钳制到画布内）
- 目标宽固定 800px，高按源区域比例缩放 → 车牌照片始终高分辨率，卡片上 contain 完整显示

### 4.4 预检单卡片生成（generateImage）

1. 加载车牌照片（`platePhoto` 为空的旧记录跳过）
2. `buildLayout`：用临时 canvas 测量三行信息（变速器/排气管/公里数）文字宽度，计算换行与行高、总高
3. 绘制：白色背景 → 头部蓝色渐变（站名、序号徽章）→ 车牌框（白色圆角卡 + 照片 contain，无照片时绘制车牌文本）→ 信息区两列（`drawCell`）→ 页脚分隔线 + 预检员·时间
4. 输出 `canvas.toDataURL('image/png')`（2x DPR 渲染）

### 4.5 分享三级降级（shareCard）

```
① Capacitor Share 插件（APK 内）：
   Filesystem.writeFile('precheck/card.png', base64, CACHE)
   → Share.share({ files: [file:// URI] })
   注：不可直接传 base64 dataURL——Android 上微信收图失败闪退（已踩坑修复）
② Web Share API（navigator.share + canShare + File 对象）
③ 提示：微信内引导长按发送；其他环境引导保存图片
```

### 4.6 提交生成（form submit）

校验（车牌照片必填）→ `buildRecord` → `generateImage` → 记录 `unshift` + 保存 → `showPreview` → **自动触发分享**（异步等 File 就绪）。

## 5. 构建与部署

### 5.1 云端构建（GitHub Actions）

1. Checkout → Node 20 → Java 21（Capacitor 必须 ≥21）
2. `npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/share @capacitor/filesystem`
3. `npx cap add android`（临时生成原生工程）
4. `node scripts/patch-android.mjs`（注入 CAMERA 权限；排除 kotlin-stdlib-jdk7/8 重复类）
5. `npx cap sync android` → `gradlew assembleDebug` → 上传 artifact `precheck-apk`
6. 触发条件：push 到 main（docs/README 变更除外）+ workflow_dispatch；打 tag 时额外生成 Release

### 5.2 本地调试

静态服务器指向 `www/`（如 `node static-server.js <www目录> 8765`），浏览器访问 `http://localhost:8765`。注意：摄像头需 https 或 localhost。

## 6. 兼容性与已知限制

- WebView 无 `navigator.share` → 走降级提示；APK 内置插件不受影响
- 卸载重装 → localStorage 清空（无数据恢复手段）
- 相册选图在部分安卓系统 WebView 表现为"文件选择器"而非直接相机
- 记录图片为压缩图（800px），满足微信群查看，不用于印刷级
