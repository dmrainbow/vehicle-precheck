# 车辆预检单登记工具 · 需求说明

版本：v2.0（定稿，与实现一致）
日期：2026-08-08
状态：已实现并交付（APK）

> 历史：v1.0（2026-08-04）含 OCR 车牌识别与多字段表单，开发中经用户确认大幅精简并废弃识别，见「7. 需求变更记录」。

---

## 1. 项目背景

检测站预检岗位每天需对进站车辆做预检登记，并把预检单发给检测线、发到工作微信群。原流程手工填写纸质单，再拍照发微信群，效率低且易出错。

本工具目标：让预检员用手机完成「拍车牌照 → 补录信息 → 生成预检单图片 → 分享微信群」全流程，替代纸质单。

## 2. 目标用户与使用场景

| 项 | 内容 |
|---|---|
| 目标用户 | 检测站预检员（非技术人员，日常使用微信） |
| 使用设备 | 本人智能手机（安卓为主） |
| 使用场景 | 车辆进站时，在车旁或工位快速登记；办结后把预检单发到工作微信群 |
| 使用频率 | 每日数十台，单台操作目标 1 分钟内完成 |

## 3. 核心需求

### 3.1 车牌照片（必填，替代车牌号文本）

- 点「拍摄车牌照片」打开摄像头，画面中央有**大取景框**（宽约 98%、高约 22%）
- 车牌对准取景框 → 点「拍照」→ 自动按取景框区域**裁剪并放大**，照片**直接回填主界面**并关闭拍照界面（无确认步骤）
- 主界面照片全宽预览，可随时「重拍车牌照片」
- 无法调用摄像头（权限拒绝/非 https）时，自动降级为**从相册选择**照片
- 未拍照片时点「生成预检单」给出红框提示，不生成

### 3.2 车辆信息录入（共 4 项）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 车牌照片 | 拍照/选图 | 是 | 裁剪 800px JPEG，作为车牌凭证展示 |
| 变速器 | 单选 | 否 | 手动挡 / 自动挡 |
| 排气管数量 | 单选 | 否 | 1 / 2 / 4 / 6 / 8 |
| 行驶公里数 | 数字 | 否 | 单位 km |

### 3.3 预检单生成与分享

- 点「生成预检单」：绘制卡片图片（750px 宽），自动保存记录、弹出预览、**自动弹出系统分享面板**
- 卡片内容：站名、标题"车辆预检单"、序号徽章（当日从 1 起）、**车牌照片（车牌框内完整显示）**、变速器/排气管数量/行驶公里数信息行、预检员·日期·时间页脚
- 分享：系统分享面板（APK 内）→ 选微信 → 选群聊发送图片；不支持的环境依次降级为 Web Share → 长按/保存图片提示
- 生成后可选「再录一台」（清空重来）或「完成」（跳记录页）；预览可关闭、可保存图片

### 3.4 记录管理

- 今日记录列表：车牌照片缩略图、序号、变速器/排气管/公里数、登记时间
- 点击记录可重新生成该车预检单卡片
- 支持删除单条（二次确认）、清空今日全部
- 导出 CSV：今日全部记录（序号/登记时间/车牌照片标记/变速器/排气管数量/行驶公里数/预检员），Excel/WPS 可打开
- 数据仅存手机本地（localStorage），无网络依赖

### 3.5 设置

- 检测站名称、预检员姓名，保存后即时生效并体现在卡片与页面标题上

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 离线 | 完全离线可用：无 CDN、无后端、无任何网络请求 |
| 隐私 | 数据不离开手机；无统计、无上报 |
| 兼容 | 移动端优先；安卓 WebView 与网页浏览器可用 |
| 性能 | 单台录入 ≤ 1 分钟；照片裁剪/卡片生成秒级完成 |
| 易用 | 全中文界面，大按钮（≥44px 触控高度），核心操作一次点击 |
| 分发 | 打包安卓 APK 可安装；同时保留纯网页版可部署任意静态托管 |

## 5. 验收标准（与测试用例.md 对应）

- 拍照回填、卡片生成、分享微信主链路全部可用（用例 G01/G03/G04）
- 四项字段与照片正确体现在卡片与 CSV（F01–F05、E01）
- 完全离线可用（飞行模式验证通过）

## 6. 已明确不做（当前版本范围外）

- 车牌号文本输入与格式校验（照片即车牌）
- OCR 自动识别车牌（已废弃）
- 车辆类型、燃油、驱动形式、检测线、预检项目、整车照片、备注等字段
- 服务器同步、多端共享、授权/激活机制
- 微信小程序版本（评估过：需重写 UI + 企业主体资质，未立项）
