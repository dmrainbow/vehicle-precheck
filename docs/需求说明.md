# 车辆预检单登记工具 — 需求说明

版本：v1.0
日期：2026-08-04
状态：已实现（开发中，待 APK 打包交付）

---

## 1. 项目背景

检测站预检岗位每天需对进站车辆做预检登记：记录车辆信息并向前台/检测线传递预检单。原流程手工填写纸质单，再拍照发微信群，效率低且易出错。

本工具目标：让预检员用手机完成「录入 → 生成预检单图片 → 分享微信群」全流程，替代纸质单。

## 2. 目标用户与使用场景

| 项 | 内容 |
|---|---|
| 目标用户 | 检测站预检员（非技术人员，日常使用微信） |
| 使用设备 | 本人智能手机（安卓为主） |
| 使用场景 | 车辆进站时，在车旁或工位快速登记；办结后把预检单发到工作微信群 |
| 使用频率 | 每日数十台，单台操作目标 1 分钟内完成 |

## 3. 核心需求

### 3.1 车牌号录入（最高频字段）

- 支持**摄像头识别车牌自动填入**：打开识别界面 → 取景框对准车牌 → 自动识别 → 人工确认后填入
- 识别失败时支持重试、拍照/选图识别、直接手动输入
- 车牌格式：省份汉字（设置中配置，默认"粤"）+ 字母数字组合；识别结果统一大写
- 识别结果必须人工确认后才生效（防误识别）

### 3.2 车辆信息录入

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 车牌号 | 文本 | 是 | 格式校验（省市前缀 + 5-7 位字符） |
| 车辆类型 | 文本 | 是 | 如：小型轿车、小型客车、货车 |
| 燃油类型 | 单选 | 是 | 汽油 / 柴油 |
| 变速器 | 单选 | 是 | 手动挡 / 自动挡 |
| 驱动形式 | 单选 | 是 | 前驱 / 后驱 / 四驱 |
| 行驶公里数 | 数字 | 否 | 单位 km |
| 车辆照片 | 图片 | 否 | 拍照或相册选择，可预览、可重拍 |
| 预检项目 | 多选 | 否 | 外检、安检 等，chips 点选 |
| 检测线 | 单选 | 否 | 1号线 / 2号线 |
| 备注 | 多行文本 | 否 | 如"未带行驶证"、复检信息 |

校验：必填项缺失时红框提示并聚焦到第一个错误项，不阻塞其他输入。

### 3.3 预检单生成与分享

- 点击"生成预检单"：绘制卡片图片（750px 宽，站名/序号/车牌/信息表/页脚），自动保存记录并弹出预览
- 卡片内容：站名（设置）、"车辆预检单"标题、序号徽章（每日从 1 起）、车牌大字号、车辆信息两列表格、备注、预检员·日期·时间页脚
- 分享：微信内长按直发群聊引导 / 系统分享面板 / 保存图片，三级降级
- 生成后提供"再录一台"（清空重来）与"完成"（跳记录页）

### 3.4 记录管理

- 今日记录列表：车牌、车辆类型、项目/线、时间；支持删除单条、清空全部
- 导出 CSV：今日全部记录，含所有字段与时间
- 数据仅存手机本地（localStorage），无网络依赖

### 3.5 设置

站名、预检员姓名、省份（车牌识别前置字），保存后即时生效并体现在卡片上。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 离线 | 完全离线可用：无 CDN、无后端、OCR 引擎本地内置（约 12MB） |
| 隐私 | 数据不离开手机；无任何统计/上报 |
| 兼容 | 移动端优先；安卓老 WebView 与微信内置浏览器可用；JS 语法 ES5 |
| 性能 | 单台录入 ≤1 分钟；OCR 首次加载 ≤30 秒（本地资源），之后秒级 |
| 易用 | 全中文界面，大按钮（≥44px 触控高度），一次点击直达核心操作 |
| 分发 | 打包安卓 APK 可安装；同时保留纯网页版可部署任意静态 HTTPS 托管 |

## 5. 已确认的产品决策

1. 手机网页版起步 → 正式交付为**安卓 APK**（用户已确认）
2. 数据只存本地（用户明确要求"只存本地"，不做账号/同步）
3. 车牌识别用本地 OCR（Tesseract.js），不依赖第三方云识别（隐私 + 离线）
4. 只识别字母数字，省份汉字由设置前置（避免中文识别包体积与误识率）
5. 分享能力受微信限制：网页无法直接弹群选择器，采用引导长按/系统分享面板

## 6. 验收标准

- [ ] 手机安装 APK 后断网可用，录入→生成→分享全流程顺畅
- [ ] 摄像头对准车牌可识别并回填，误识别可人工修正
- [ ] 预检单卡片文字无溢出/截断，可长按直发微信群
- [ ] 今日记录、删除、导出 CSV 正常；重启 App 数据不丢
- [ ] 设置项修改后卡片即时反映
