## 二、最终功能形态（2026-08-08 定稿）

1. **表单字段（用户要求精简后）**：
   - 车牌照片（必填，拍照代替车牌号文本）
   - 变速器（手动挡/自动挡）
   - 排气管数量（1/2/4/6/8）
   - 行驶公里数（km）
   - 已删除：车辆类型、燃油、驱动形式、检测线、预检项目、整车照片、备注、车牌号文本输入
2. **车牌拍照流程**：
   - 点「拍摄车牌照片」→ 摄像头 + 大取景框（98% 宽 × 22% 高，边框 3px）→ 点「拍照」→ 按取景框裁剪（800px 宽 JPEG）→ **直接回填主界面并关闭弹窗**（无确认步骤）
   - 主界面照片全宽预览，旁边「重拍车牌照片」按钮可重拍
   - 无法调摄像头时降级为相册选图
   - 摄像头请求 1920×1080；`cropPlatePhoto()` 裁剪时按取景框比例放大
3. **预检单卡片**：车牌框位置直接显示车牌照片（contain 完整显示，PLATE_BOX 130/150/670/150），下方信息行（变速器/排气管/公里数）
4. **生成即分享**：点「生成预检单」→ 生成 PNG 卡片 → **自动弹系统分享面板**（微信等），分享面板中选微信群即可发送
   - 实现：Capacitor Share + Filesystem 插件，图片先写入 `cache/precheck/card.png` 再以文件路径分享（base64 直传会失败——微信闪退问题已修复）
   - 浏览器环境降级：Web Share API → 长按/保存提示
5. **记录**：今日记录列表显示车牌照片缩略图 + 序号 + 变速器/排气管/公里数；CSV 导出含"车牌照片（照片）"占位列

## 三、技术要点（重要，勿回退）

- **不要恢复 Tesseract OCR**：用户明确废弃识别，改纯拍照预览（此前识别不准）
- **微信分享必须走文件路径**：`Filesystem.writeFile → Share.share({files:[uri]})`，直接传 base64 dataURL 会闪退
- **依赖**：`@capacitor/core|cli|android|share|filesystem`（Actions 内 npm install，非本地 package.json）
- **构建**：Java 21；`scripts/patch-android.mjs` 注入 CAMERA 权限 + kotlin-stdlib exclude；`npx cap add android` 在 Actions 内临时生成
- **workflow 已加 paths-ignore**（docs/**、README.md 不触发构建）
- 仓库：`https://github.com/dmrainbow/vehicle-precheck`（main，dmrainbow）
